# Qol_Improvements
A basic mod for Slendytubbies 3 Multiplayer that adds some improvements to the game.

## Requirements:
1. MelonLoader 7.x Il2cpp CoreCLR. It may work with older versions, but not guaranteed.
2. Latest version of Slendytubbies 3 Multiplayer and the mod for that specific version

## Features:

### Better Theater Fly Cam:
This adds some features to the Fly Cam in Theater, such as spectating through player POV

#### Controls:
O - Toggle menu

P - Toggle target POV

Scroll wheel - Scroll through targets
